# AI Inference Academy

A hands-on curriculum for learning LLM inference from first principles: understand the basics, then build the system.

- **Engine track** — build a small inference engine (KV cache, continuous batching, PagedAttention, kernels, quantization, speculative decoding, parallelism).
- **Platform track** — build an inference platform (Go gateway, GPUs on Kubernetes, cache-aware routing, autoscaling, observability, cost).
- **Capstone** — combine both into MiniServe and defend it in a design review.

See [CURRICULUM.md](CURRICULUM.md) for the full plan.
